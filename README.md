> **Статус системы:** Экспертная база знаний военно-инженерного уровня.

## 📐 ПРИНЦИПЫ ФОРМИРОВАНИЯ ДЕРЕВА ЗНАНИЙ

1. **Инкапсуляция границ:** Мы не учим «всё IT». Всё, что находится за пределами активного отсека, для системы физически не существует.
2. **Физика вместо зубрежки:** Каждый инструмент завязан на поведение железа (процессор, RAM, жесткий диск). Если понимаешь физику — синтаксис пишется на автомате.
3. **Консервация капканов:** Любая ошибка на полигоне немедленно заносится в бункер как «капканный узел» с готовым решением-бронежилетом.
